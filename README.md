# Sparrow Math &mdash; C++ Library

## Development Tool:
The `dev.sh` file can be used to build, rebuild, and run the project. It can be run in the following ways:
1. Run `./dev.sh build-cpp` (or `./dev.sh`) to compile the CPP and HPP files
2. Run `./dev.sh build-cmake` to compile the CMake, CPP, and HPP files.
3. Run `./dev.sh build-conan` to install the Conan libraries and compile the CMake, CPP, and HPP files.
